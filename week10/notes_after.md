# week09/tools.py 함수 정리

## 개요
- 영화진흥위원회(KOBIS) 일별 박스오피스 API를 부르는 함수 모음임
- API 키는 secret.py 의 `API_KEY` 를 가져와 씀
- 요청 주소는 `BASE_URL` (searchDailyBoxOfficeList.json) 하나를 같이 씀

## 함수 목록

### 1. `get_boxoffice_rank_1(date)`
- 하는 일: 그 날짜의 박스오피스 1위 영화 제목을 돌려줌
- 받는 값: `date` — 8자리 날짜 문자열 (예: "20261103")
- 돌려주는 값: 1위 영화 제목 문자열 (예: "오디세이")
- 동작 순서
  - API 키와 날짜를 넣어 API에 요청함 (10초 넘으면 중단)
  - 응답 JSON에서 `dailyBoxOfficeList` 목록을 꺼냄
  - 목록 첫 번째(`movies[0]`)의 `movieNm`(영화 제목)을 돌려줌
- docstring(함수 설명 주석)이 달려 있음

### 2. `get_movie_audience(date, title)`
- 하는 일: 그 날짜에 특정 영화의 하루 관객 수를 알려줌
- 받는 값
  - `date` — 8자리 날짜 문자열
  - `title` — 찾을 영화 제목
- 돌려주는 값
  - 찾으면: 천 단위 쉼표가 붙은 관객 수 문자열 (예: "123,456명")
  - 못 찾으면: "'제목' 은(는) 날짜 순위에 없습니다." 안내 문자열
- 동작 순서
  - 1번 함수와 같은 방식으로 박스오피스 목록을 받아옴
  - 목록을 하나씩 돌며 `movieNm` 이 `title` 과 똑같은지 비교함
  - 맞으면 `audiCnt`(그날 관객 수)를 숫자로 바꿔 쉼표 붙여 돌려줌
- docstring이 없음

## 참고할 점
- 두 함수 모두 API 요청·응답 처리 코드가 똑같이 반복됨
- 1번 함수는 목록이 비어 있으면 `movies[0]` 에서 오류가 남
- 2번 함수는 제목이 글자 하나라도 다르면(띄어쓰기 등) 못 찾음
